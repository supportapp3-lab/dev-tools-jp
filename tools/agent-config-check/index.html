    使い方と注意点

    設定を貼り付け、チェックボタンを押すと、該当する行と見直しのヒントを表示します。「サンプル入力」で試せます。入力を編集したら、もう一度チェックしてください。

    これは文字列パターンによる簡易検出です。ファイル形式の完全な解析や設定の安全性の保証は行いません。コメント・複雑な入れ子・独自形式では見逃しや誤検出があり、検出なしでも安全とは限りません。

    貼り付けた入力欄には元の値が表示されます。画面共有や拡張機能にも注意し、共有前には「入力を消去」を押してください。外部送信・保存・広告・アクセス解析はありません。
