文字数・トークン数カウンター

テキストを入力すると文字数やUTF-8バイト数を数え、トークン数を概算します。入力内容が外部へ送信されることはありません。

テキストを入力

最大1MB。入力内容は送信・保存されず、このページ内だけで処理されます。

トークン数は文字種別による目安です。実際のモデル用トークナイザーの結果ではなく、モデル・バージョン・文章によって差があります。正確な値や料金は保証しません。

使い方と注意点

テキストを貼り付けるか入力例を選ぶと、約100ミリ秒後に集計が更新されます。空白区切りの語数は、空白を使わない日本語などでは参考値です。

トークン数は概算です。英数字などはGPT系を約4文字で1トークン、Claude系を約3.5文字で1トークンとして計算します。漢字・かななどのCJK文字はGPT系を約1文字あたり1トークン、Claude系を約1文字あたり1.3トークンとして計算します。これは一般的な目安で、実際のモデル用トークナイザーではありません。モデルや文章によって結果は変わるため、正確なトークン数・料金の見積もりには使えません。

このツールは入力内容を外部に送信せず、保存・ログインもしません。解析はブラウザ内で完結します。機密情報の取り扱いは、お使いの端末やブラウザの設定にも注意してください。
