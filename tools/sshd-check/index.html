SSHサーバー設定を、接続を切る前に確認

sshd_config安全チェッカー

設定ファイルを貼り付けると、認証・転送・暗号の気になる項目を日本語で表示します。
入力内容は送信・保存されず、このページ内で処理します。

01 sshd_config を入力

最大1MB。コメント（#以降）は解析対象外です。Include先のファイルは読み込みません。

02 確認結果

入力後に「設定をチェック」を押してください。

≡

貼り付けた設定の指摘をここに表示します。

Matchブロックは別に表示し、グローバル設定の判定には使いません。

    Include（内容は未確認）

      Match ブロック内（グローバル判定から除外）

        使い方と注意点

        設定全体を貼り付けて「設定をチェック」を押します。大文字・小文字は区別せず、#以降はコメントとして扱います。同じキーワードが複数ある場合は最初のグローバル設定を判定に使い、重複を表示します。

        Matchブロック内の行はグローバル設定に混ぜず、別欄に表示します。Include先の設定は取得しません。実効値は接続元・ユーザー・OpenSSHのバージョン・Include先などで変わるため、ここでの結果は簡易確認です。

        OpenSSHの既定値はバージョンによって異なります。PermitRootLoginやPasswordAuthenticationが未指定でも、実際の安全性を断定できません。Port 22は情報表示で、ポート番号の変更だけではセキュリティの本質的な対策になりません。

        設定を変更した後は sudo sshd -t で文法を確認してください。現在のSSH接続を切らずに、別ターミナルからログインできることを確かめてください。

        外部送信・保存・ログイン・広告・外部スクリプトはありません。結果は設定全体の安全性を保証するものではありません。
